**Purpose:** Define AI work before execution so that scope, authority, evidence and human accountability remain explicit.

# Before execution

Ask the agent to:

1. Restate the assignment in its own words.
2. Identify unresolved decisions and conflicting instructions.
3. Confirm the sources it will treat as authoritative.
4. List the evidence it will produce.
5. Describe the actions it intends to take.

Do not begin consequential execution while a material ambiguity remains unresolved.

# At completion

Require the agent to:

1. Map the result to every acceptance criterion.
2. Attach or reference the required evidence.
3. List every exception and unresolved issue, including failed conditions.
4. Identify any action taken outside the original plan.
5. Present the result for human approval.

**Model completion is not approval. A human remains accountable for consequential use.**

---

## Non-goals

This template does not:

- guarantee that the task is correctly designed;
- replace a security sandbox or access-control system;
- verify that source data are true;
- approve the result;
- transfer accountability to an AI model.

---

**Mensurabilitas™:** AI is not a tool. AI is a team member.

Responsibility never transfers to AI.
